TerraSight — the eyes & brain of an autonomous rover

An onboard Edge-AI perception stack that turns raw stereo + RGB camera feeds into a live 3D terrain map, classifies every patch of ground into actionable zones, and scores it for construction — without waiting on Earth.

Latency killer: decisions made onboard, not 40 min round-trip Core: Semantic Segmentation + V-SLAM Runs on: quantized model, rad-hard CPU budget
The output that matters

01 — Four zones the rover reasons about

Instead of streaming video for a human to interpret, TerraSight labels the world into four decision classes. Every downstream module — navigation, mission planning, the Earth dashboard — consumes these labels.

Zone 0

Construction-safe

Flat, compacted regolith, high bearing capacity, sub-threshold slope. Cleared for habitats, pads & arrays.

Zone 1

Navigation only

Uneven or loose soil — safe to drive across, unsafe to build on. Path-planner may traverse, planner won't site.

Zone 2

Geological interest

Ancient water beds, ice deposits, mineral boundaries. Flagged for science, protected from disturbance.

Zone 3

Hazardous

Crater rims, steep slopes, large boulders. Hard no-go — the planner routes around it.

04 — From pixels to a classified 3D map

The hard part. A single frame is turned into (a) a per-pixel class raster and (b) a metric point cloud, then fused into a slope/roughness map registered to the SLAM pose graph.

Fig 3 — segmentation answers "what is it", stereo answers "where & how steep"; zones need both.

Why segmentation and depth

  • Class alone is ambiguous: flat-looking regolith on a 25° slope is still Zone 3.
  • Depth alone is blind to material: a flat ice sheet reads as buildable but is Zone 2.
  • Fusion resolves it: a cell is Zone 0 only when class = compact soil and slope < threshold and distance-to-crater > margin.

Detecting the "limits of soil"

  • Sharp depth gradient along a boundary → crater rim / cliff edge.
  • Texture + albedo discontinuity with low slope → dried liquid bed / mineral edge (Zone 2).
  • Boundaries are vectorized and sent as polylines, cheap to transmit vs. raster.

07 — Edge cases & their solutions

Space is physically hostile to camera-based AI. Naming these — with a concrete mitigation for each — is what separates a demo from a mission concept.

Edge caseSevWhy it breaks a naive systemTerraSight mitigation
Pitch-black shadows & blinding sun HIGH No atmospheric scatter → zero-info shadows and blown highlights fool the segmenter into false rock/hole calls. Extreme contrast + gamma augmentation in training; treat pure-black regions as unknown, not hazard; HDR-style tone mapping at ingest.
Rad-hard CPU is slow & power-limited HIGH Full-precision U-Net won't hit frame budget; drains battery. INT8 quantization + pruning; run segmentation at reduced cadence, depth every frame; skip inference when scene is static (frame-diff gate).
Featureless terrain → SLAM drift HIGH Uniform regolith gives no visual features; pose estimate diverges, map warps. Fuse IMU + wheel odometry with visual SLAM; drop confidence weight when feature count is low; flag map region as "low-trust".
Repetitive texture aliasing MED Similar-looking rocks cause false loop closures / bad stereo matches. Left-right consistency check on disparity; reject matches above ambiguity threshold; multi-scale features for loop closure.
Dust on lens / motion blur MED Degraded frames silently poison the map with garbage geometry. Per-frame quality gate (blur variance, exposure); drop bad frames; hold last-good map rather than overwrite.
Domain gap (Earth-trained model on alien soil) MED Model trained on Mars analog underperforms on lunar regolith. Rules layer is decoupled from the net — geometry (slope/depth) still works even if class is uncertain; class confidence gates the zone decision.
Downlink loss / partial transfer MED Dropped packets corrupt the Earth map; bandwidth can't fit full raster. Tile-based delta encoding with priority (hazards + high-score sites first); idempotent tiles; dashboard renders best-available, marks stale tiles.
Ambiguous / conflicting zone signals LOW Flat but loose, or class says soil while slope says hazard. Conservative precedence: hazard > geological > nav > safe. When in doubt, never label Zone 0.
Thermal / sensor timestamp skew LOW Unsynced stereo frames wreck disparity and pose. Hardware-synced capture where possible; software timestamp matching with a max-skew reject window at ingest.
